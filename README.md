# Vite + TypeScript + React Habit tracker app

a simple front-end app that lets you manage and track your habits

<br>

## if you want to test this project on your local machine you need to follow these steps:

### 1. Open your terminal:
### 2. Choose the directory you want (ex: desptop):
### 3. Enter the command:
```bash
git clone https://github.com/black-purple-jr/react-habit-traker
```
### 4. Enter the cloned directory and enter this command:
```bash
C:/.../react-habit-tracker> npm install
```

### 5. Run a development server:
```bash
npm run dev
```

### 6. Open a browser and enter the URL displayed on your terminal (http://localhost:5173/ by default, but you should follow he one displayed on your terminal if it uses a different port)
